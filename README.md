# Viktória Šišková – Personal Portfolio Website

This repository contains a **minimal, one-page personal portfolio website** used to present my professional profile, experience, and contact details.

The site is intentionally simple, fast, and recruiter-friendly.

---

## 🌐 Live Website
Once GitHub Pages is enabled, the site will be available at:

```
https://<your-github-username>.github.io/<repository-name>/
```

Example:
```
https://viktoria-siskova.github.io/portfolio/
```

---

## 📁 Project Structure

```
/
├── index.html   # Main one-page website
└── README.md    # Project documentation (this file)
```

There are no external dependencies, build steps, or frameworks.

---

## 🚀 How to Deploy (GitHub Pages)

1. Upload `index.html` to this repository
2. Go to **Settings → Pages**
3. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Save

Your site will be live within 1–2 minutes.

---

## ✏️ How to Update Content

You can update the site directly from the **GitHub mobile app**:

1. Open `index.html`
2. Tap **Edit**
3. Modify text (bio, skills, links, email, etc.)
4. Commit changes

Updates are published automatically.

---

## 🌍 Custom Domain (Optional)

To use a custom domain (e.g. `viktoriasiskova.com`):

1. Go to **Settings → Pages**
2. Add your custom domain
3. Configure DNS records at your domain provider
4. Enable HTTPS when prompted
